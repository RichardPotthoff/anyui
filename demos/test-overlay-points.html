Overlay + PointHandles

Two layers share the same view transform \(V\). Content draws a shape + grid; PointHandles draws the three points on top. Change the active layer to route pointer events; opacity shows which layer is in front.

Gestures on empty space: 1-finger / mouse-drag = pan · wheel / 2-finger pinch = zoom around focal point. Dragging a handle still moves the point (PointHandles wins on hit).
