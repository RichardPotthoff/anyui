Dual Overlay + Möbius link

Source (blue) and image (orange) share the scene via a Möbius \(M\). Clear canvases; Overlay supplies the paper background.

Source side: drag handles → move \(z_i\), keep \(M\), image points follow \(w_i=M(z_i)\).
Image side: drag handles → move \(w_i\), refit \(M\) from the three pairs.
Pan/zoom updates only the active side’s view \(V\). Image drawing + grid are under \(M\) then \(V_i\).
